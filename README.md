# Hybrid 3D-CNN–Vision Transformer for Wheat Variety Classification

This repository contains the implementation of the hybrid deep learning
framework described in the manuscript:

"Hybrid Local Spectral-Spatial–Global Contextual Feature Based Wheat Variety
Classification Using Hyperspectral Imaging Data"

## Overview

This study presents a hybrid deep learning framework for wheat variety
classification using hyperspectral imaging data.

The proposed framework combines:

- 3D Convolutional Neural Network (3D-CNN) for local spectral-spatial
  feature extraction
- Vision Transformer (ViT) for global contextual feature learning
- Concatenation Feature Fusion (CFF) for integrating complementary features
- Fully connected classification layer for wheat variety prediction

The framework is evaluated on the HyperLeaf2024 dataset.

## Dataset

The experiments use the publicly available HyperLeaf2024 dataset.

Dataset location:

https://www.kaggle.com/competitions/HyperLeaf2024/data?select=images

The dataset contains hyperspectral images of four wheat cultivars:

- Heerup
- Kvium
- Rembrandt
- Sheriff

The dataset used in the study contains 2,410 hyperspectral images, including
1,590 training images and 820 testing images.

## Preprocessing

The preprocessing pipeline includes:

1. Spectral normalization
2. Gaussian noise reduction
3. Image resizing

These steps are applied before feature extraction.

## Model Architecture

The proposed architecture consists of two complementary branches.

### 3D-CNN

The 3D-CNN extracts local spectral-spatial features from the hyperspectral
images by processing spatial and spectral dimensions jointly.

### Vision Transformer

The Vision Transformer processes image patches and uses self-attention to
capture global contextual relationships.

### Concatenation Feature Fusion

The feature representations generated by the 3D-CNN and Vision Transformer
are concatenated to create a unified hybrid feature representation.

The fused representation is passed through the classification layer.
